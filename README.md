# family-apps
Phone apps, the hosted screen and the first-time setup wizard for the Family Dashboard.
Upload everything in this folder to the root of the GitHub repository (Settings → Pages → main branch).

- setup/      – first-time setup wizard (setup/config.js: optional templateId of a clean template Sheet)
- admin/      – Family Admin phone app
- calendar/   – Family Calendar phone app
- screen/     – the dashboard itself, for a Raspberry Pi or tablet browser
- downloads/  – screen files for a Windows PC
None of these files contain an access code or web app address.
