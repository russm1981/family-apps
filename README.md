# family-apps
The Family Dashboard's apps, hosted on GitHub Pages. Upload everything in this folder to the root of the repository.

- index.html  – front page: Setup, Windows screen download, Family Calendar, Family Admin (with QR codes)
- setup/      – first-time setup app (setup/config.js: templateId of the clean template Sheet)
- screen/     – the dashboard itself (Windows launcher, Raspberry Pi, tablets)
- admin/, calendar/ – phone apps
- downloads/  – Windows launcher
- version.json – current app and script versions (raise these when you release an update)
- privacy.html, shared/privacy.js – privacy notice (raise its version to ask everyone to accept again)

No access codes or web app addresses are stored in these files.
