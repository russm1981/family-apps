# family-apps
The Family Dashboard's apps, hosted on GitHub Pages. Upload everything in this folder to the root of the repository.

- index.html – front page (Setup, Windows screen, Family Calendar, Family Admin)
- setup/ – setup app; also used to change things later (setup/config.js: templateId of the template Sheet)
- screen/ – the dashboard · admin/, calendar/ – phone apps · downloads/ – Windows launcher
- version.json – current versions · privacy.html, shared/privacy.js – privacy notice

No access codes or web app addresses are stored in these files.
