Help

The screen says “Can’t reach the Google Sheet”

Usually the screen is using an old or mistyped link. Open Setup → “Connect your devices” (or your Sheet → 🏠 Family Dashboard → Connect my screen and phones) and use the new start file or screen link. If it says “Wrong access code”, the code was changed – use the new links.

“Your Google script needs updating”

Open your Sheet → Extensions → Apps Script, paste in the new Code.gs, Save, then Deploy → Manage deployments → pencil → Version: New version → Deploy. Saving alone isn’t enough – the new version has to be deployed. Setup’s “Updates” step shows the details.

How updates work
  • Screen: checks every 10 minutes and updates itself when nobody is using it (or offers “Update now”). The version number is at the bottom of its side bar.
  • Phone apps: update themselves next time they’re opened.
  • Google script: the only part updated by hand (see above).

Voice commands

Tap the microphone at the bottom of the screen’s side bar, wait for the beep, then say for example “Ben add 15 points”, “calendar add Ben drums at 12 on Saturday”, “memo dentist moved to Thursday”, “add milk to the shopping list”, “timer 10 minutes” or “go to calendar”. Say “help” for more.
