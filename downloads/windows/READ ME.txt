FAMILY DASHBOARD FOR WINDOWS (Corsair XENEON EDGE, or any PC screen)

1. Put "Start Family Dashboard.bat" somewhere permanent, e.g. Documents\Family Dashboard.
   Easiest: use the personal start file from the setup app (step "Connect your devices") -
   it already knows your Google Sheet.
2. Double-click it. The first time it asks two Yes/No questions:
   - start automatically when the PC turns on?
   - keep the screen switched on?
   (If Windows says "Windows protected your PC": More info > Run anyway.)
3. The dashboard opens full screen. Close it with Alt+F4.
   If it asks you to connect, scan the QR code with your phone.

Nothing needs updating by hand. The start file only holds your link: each time it starts it
fetches the latest launcher from the internet (keeping a copy for when the internet is down),
and the dashboard itself loads from the internet, so it is always the newest version.
To be asked the two questions again, delete startup-answer.txt / screen-answer.txt in
%LOCALAPPDATA%\FamilyDashboardKiosk.
