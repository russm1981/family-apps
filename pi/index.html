HouseRunner on a Raspberry Pi

Turn a Raspberry Pi into a dashboard screen – for example on the back of a Corsair XENEON EDGE. One line sets it all up: full screen at every start, screen kept on, security updates by itself.

What you need

  • A Raspberry Pi 4 or 5 with its power supply, and a microSD card (16 GB or more).
  • The screen, plus a keyboard and mouse for the setting up (you can unplug them afterwards).
  • A computer to put Raspberry Pi OS on the card.

1. Put Raspberry Pi OS on the card

  1. On your computer, install Raspberry Pi Imager and open it.
  2. Choose your Pi, then Raspberry Pi OS (64-bit) – the one “with desktop” – then the microSD card.
  3. When it asks about settings, choose Edit settings: set a username and password, and your Wi-Fi name and password (skip Wi-Fi if you’ll use a network cable). Then write the card.

2. Start the Pi and run the one line

  1. Put the card in the Pi, plug in the screen, keyboard, mouse and power. Wait for the desktop.
  2. Open Terminal (the black window icon at the top of the screen).
  3. Type this line exactly, then press Enter:
curl -sL houserunner.app/pi.sh | bash

Tip: on the Pi you can open this page in its web browser (houserunner.app/pi), press Copy, and paste into Terminal with Ctrl+Shift+V.

It takes a few minutes. When it says it’s done, restart the Pi (or type sudo reboot).

3. Connect it to your family

After the restart the dashboard opens full screen and shows a code like K7Q2-M9XD. Not set up yet? Scan its QR code with your phone – it takes you through setup first. Already set up: on your phone, Family Admin → More → Connect a display, or on a computer that’s set up, houserunner.app → Home → Type a display’s code.

That’s it. Nothing needs updating by hand: every start it loads the newest dashboard, and the Pi installs its own security updates and restarts itself at 4 am.

Setting one up for someone else’s home?

Use this line instead. The first time the Pi starts somewhere without known Wi-Fi, it makes its own Wi-Fi network called Pi-HouseRunner: join it from a phone, pick the home’s Wi-Fi and type its password.

curl -sL houserunner.app/pi.sh | bash -s -- --wifi-setup
Something not working?
  • “curl: not found” or nothing happens – check the Pi is on the internet (the Wi-Fi symbol at the top right), then try again.
  • The screen goes blank – that’s the dashboard’s own night-time sleep (set in System → Display Sleep). Touch the screen or move the mouse.
  • To stop it starting by itself – press Alt+F4 to close it, open Terminal and type sed -i '/family-dashboard/d' ~/.config/labwc/autostart; rm -f ~/.config/autostart/family-dashboard.desktop
  • More help: Help → Raspberry Pi.
