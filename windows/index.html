HouseRunner for Windows

For the Corsair XENEON EDGE, or any screen on a Windows PC. It runs the dashboard full screen, can start with the PC, and updates itself.

1. Download

Download HouseRunner for Windows

A small zip file. Open your Downloads folder, right-click it → Extract All…, and put the folder somewhere permanent, e.g. Documents\HouseRunner.

2. Start it

  1. In the folder, double-click Start HouseRunner. If Windows says “Windows protected your PC”: More info → Run anyway.
  2. The first time, it asks two Yes/No questions: start when the PC turns on, and keep the screen switched on.
  3. The dashboard opens full screen. Close it with Alt+F4.

3. Connect it to your family

The screen shows a code like K7Q2-M9XD. On a computer, go to houserunner.app → Home → Type a display’s code – or on a phone: Family Admin → More → Connect a display.

Nothing needs updating by hand: each time it starts it fetches the newest version.
